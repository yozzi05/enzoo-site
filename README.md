# Сайт ветеринарной клиники EnZoo (Махачкала)

Многостраничный сайт на Next.js 16 (App Router, TypeScript). Без личного кабинета, регистрации, магазина и онлайн-оплаты. Основное содержание отдаётся сервером (SSG), клиентский JS — только для меню, поиска, фильтров прайса, формы и карты по запросу.

## Запуск

Нужен Node.js 20.9+ (проверено на 24.22.1 LTS).

```bash
npm ci
```

```bash
cp .env.example .env.local
```

```bash
npm run dev
```

Сайт откроется на http://localhost:3000. Production-сборка и запуск:

```bash
npm run build
```

```bash
npm start
```

Проверки:

```bash
npm run typecheck
```

```bash
npm run lint
```

```bash
npm run test:phone
```

## Публикация на GitHub Pages

Сайт для просмотра: https://yozzi05.github.io/enzoo-site/ (закрыт от индексации).

При каждом push в `main` workflow `.github/workflows/pages.yml` собирает статическую версию (`STATIC_EXPORT=1`, подкаталог `/<имя репозитория>`) и публикует папку `out/`. В статической версии нет серверной части: приёма заявок через форму, редиректов и HTTP-заголовков — запись идёт по телефону. Для онлайн-заявок нужен хостинг с Node.js (`npm run build && npm start`).

Локально собрать статическую версию (PowerShell):

```powershell
$env:STATIC_EXPORT='1'; $env:NEXT_PUBLIC_BASE_PATH='/enzoo-site'; npm run build
```

  config/
    site.ts               ← адрес, телефон, режим работы, карты, email, мессенджеры, реквизиты
    nav.ts                навигация
    redirects.ts          редиректы старых страниц
  content/
    services.ts           направления и процедуры (enzoo24.ru)
    prices.ts             модель прайса и утверждённые цены
    clinic.ts             о клинике, груминг, фото, акции, FAQ (enzoovet.ru)
  lib/
    appointment.ts phone.ts   общая клиентская/серверная валидация
    analytics.ts              события без персональных данных
    server/delivery.ts        адаптеры доставки заявок
    server/rate-limit.ts      ограничение частоты

Контакты, адрес и режим работы меняются в одном месте — `src/config/site.ts`.

## Маршруты

`/`, `/services`, `/services/[slug]` (16 направлений), `/prices`, `/about`, `/grooming`, `/reviews`, `/owners`, `/contacts`, `/appointment`, `/privacy`, `/consent`, 404. `/offers` отвечает 404, пока в `content/clinic.ts` нет подтверждённых предложений; при их появлении пункт «Акции» добавится в навигацию и sitemap.

## Подключения для запуска

| Что | Переменная | Обязательно | Комментарий |
|---|---|---|---|
| Домен сайта | `NEXT_PUBLIC_SITE_URL` | да | canonical, sitemap, Open Graph |
| Режим индексации | `NEXT_PUBLIC_SITE_ENV=production` | да, только на боевом домене | Иначе `noindex`, `X-Robots-Tag` и `Disallow: /` |
| Канал заявок | `APPOINTMENT_DELIVERY` = `telegram` или `webhook` | для онлайн-заявок | Без канала форма скрыта, сайт предлагает звонок |
| Telegram | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | при `telegram` | Бот должен быть добавлен в чат администратора |
| Webhook / CRM | `APPOINTMENT_WEBHOOK_URL`, `APPOINTMENT_WEBHOOK_SECRET` | при `webhook` | POST JSON, секрет — в `Authorization: Bearer` |
| Соль хеша IP | `RATE_LIMIT_SALT` | желательно | Для ограничителя частоты |
| Яндекс Метрика | `NEXT_PUBLIC_YM_ID` | нет | Только номер счётчика клиники |

Секреты хранятся только в переменных окружения сервера и не попадают в клиентский код.

Перед запуском также нужно заполнить реквизиты оператора данных (`site.legal`) и пройти юридическую проверку `/privacy` и `/consent`, вычитать медицинские тексты у ветеринара и, при наличии, внести утверждённые цены. Полный список — в `CONTENT_GAPS.md`.

### Подключение Telegram

1. В Telegram откройте @BotFather → `/newbot`, задайте имя и username. BotFather пришлёт токен.
2. Создайте чат для заявок (или используйте существующий), добавьте в него бота и напишите в чате любое сообщение. Для группы: в BotFather → `/setprivacy` → Disable, либо начните сообщение с `/start`.
3. В `.env.local` (на сервере — в переменных окружения) укажите:
   ```
   APPOINTMENT_DELIVERY=telegram
   TELEGRAM_BOT_TOKEN=<токен от BotFather>
   ```
4. Узнайте id чата — команда покажет чаты, в которых бот видел сообщения:
   ```bash
   npm run telegram:chats
   ```
   Впишите число в `TELEGRAM_CHAT_ID` (у групп оно отрицательное).
5. Проверьте отправку:
   ```bash
   npm run telegram:test
   ```
6. Перезапустите сайт и отправьте тестовую заявку через форму. Токен никому не пересылайте; при утечке — `/revoke` в BotFather.

### Приём заявок

- Заявка — запрос на согласование, а не бронь. Успех показывается только после ответа `201` от сервера, то есть после того, как канал доставки (Telegram API / webhook) подтвердил приём.
- `test` — адаптер для разработки: пишет заявки в `.data/test-outbox.jsonl` и **не работает** при `NODE_ENV=production`. Реальные тестовые обращения клинике не отправлялись.
- `TEST_DELIVERY_FAIL=1` (только с `test`) имитирует сбой доставки.
- Защита: серверная валидация, honeypot, ограничение 5 запросов / 10 мин на IP (в памяти процесса — для нескольких экземпляров замените на Redis), лимит тела 4 КБ и длины полей, проверка `content-type`. В логи пишутся только коды ошибок, без имени, телефона и комментария.

### Прайс и заявка на услугу

Все цены хранятся в одном месте - `src/content/prices.ts` (ID, направление, раздел, название, тип цены: фиксированная / «от» / диапазон / по запросу, сумма, единица, вид животного, категория сложности, что не входит, примечание). Эта же запись используется в полном прайсе `/prices`, на страницах направлений, в поиске каталога, в форме заявки и на сервере. Меняйте название и цену, но не ID.

Кнопка «Оставить заявку» у каждой позиции открывает общую форму в модальном окне с подставленной услугой, ценой и условиями (без JS - страница `/appointment?service=ID`). Сервер определяет название и стоимость по ID; если цена изменилась после открытия формы, заявка не уходит, а посетителю показывается новая цена и предлагается подтвердить отправку. Сверка импорта - `PRICE_IMPORT.md`.

### Аналитика

События: `call_click`, `messenger_click`, `route_click`, `appointment_start`, `appointment_success`, `appointment_error`, `service_view`. Передаются только место клика, slug услуги и код ошибки. Счётчик не подключается без `NEXT_PUBLIC_YM_ID`.

## Отчёт о проверках (28.10.2026)

Выполнено на этой машине (Windows 11, Node 24.22.1):

- `npm run build` — успешно (Next.js 16.4.3, Turbopack): 32 страницы, статические + `/appointment` и `/api/appointment` динамические.
- `npm run typecheck` (`tsc --noEmit`) — без ошибок.
- `npm run lint` (ESLint 9, `eslint-config-next` core-web-vitals + typescript) — без ошибок и предупреждений.
- `npm run test:phone` — 7/7 случаев маски телефона (набор с 8, +7, вставка, городской номер 8722, неполный номер).
- Прямое открытие всех маршрутов: 200 для 29 адресов (включая sitemap.xml и robots.txt); 404 для `/nope`, `/services/nope`, `/offers`; 308 для `/home/terapiya/` и `/services/grooming`.
- API (`curl`): GET → 405; не-JSON → 415; битый JSON → 400; honeypot → 400 без доставки; невалидные поля → 422 с ошибками по полям; тело > 4 КБ → 413; шестой запрос подряд → 429; в production без канала → 503.
- Форма в браузере: предзаполнение услуги из `?service=`, ошибки у полей и фокус на первой ошибке, маска телефона, двойное нажатие Enter → один POST и одна запись в outbox, успех только после ответа сервера; при сбое доставки — сообщение у кнопки, данные сохранены, предложен звонок; в production без канала форма заменена звонком.
- Каталог: поиск по процедурам («зуб» → стоматология + грызуны), синхронизация `?q=`, пустое состояние со сбросом.
- Прайс (с демо-данными): фильтры из URL, поиск, пустое состояние, сброс очищает URL; длинные названия переносятся (проверено на desktop).
- Клавиатура: skip-link первым по Tab, видимое кольцо фокуса; мобильное меню открывается с клавиатуры, Escape закрывает и возвращает фокус, `aria-expanded` обновляется.
- SEO: один H1, уникальные title/description, canonical от `NEXT_PUBLIC_SITE_URL`, JSON-LD `VeterinaryCare` и `BreadcrumbList` парсятся, sitemap из 27 адресов, robots и `X-Robots-Tag` закрывают preview.
- Визуально проверены ширины 360, 390, 768, 1024, 1440 и 1920 px (главная, услуги, страница направления, груминг, «О клинике», «Владельцам», заявка, прайс): горизонтальной прокрутки нет, нижняя панель скрыта на странице заявки.

Не выполнялось: Lighthouse и автоматический аудит доступности (axe), проверка в Safari/iOS и Firefox, прайс с демо-данными на телефоне, отправка через реальные Telegram/webhook (нет согласованного канала), нагрузочное тестирование.
